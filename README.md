### 📖 About the Project
This portfolio serves as a central hub to showcase my expertise in native Android development. Unlike standard templates, this site features a custom-built Android IDE-inspired aesthetic, complete with a mockup phone frame displaying a live Compose-style UI, logcat-style tags, and a fluid dark/light mode toggle. 

It highlights my professional experience, featured apps, technical stack, and includes a fully functional client-side Resume PDF generator.

---

### ✨ Key Features

#### 🎨 Modern Design & UI
- **Dark/Light Theme Toggle:** A seamlessly integrated theme switcher with local storage persistence.
- **Glass Morphism & Grid Lines:** Subtle background grids and glassmorphic floating tech chips (Kotlin, Compose, Firebase, MVVM).
- **Custom Phone Mockup:** A pure CSS/HTML Android phone frame that responds to mouse parallax.
- **IDE Aesthetic:** Logcat-style section tags (e.g., `D/PROFILE`, `I/ABOUT`) to keep the Android developer vibe strong.

#### ⚡ Advanced Interactivity
- **GSAP-Powered Animations:** Smooth scroll reveals, hero entrance timelines, and parallax scrolling effects.
- **Typing Effect:** Dynamic role rotation in the hero section.
- **Interactive Testimonials:** Custom-built slider with autoplay, dots, and hover-to-pause functionality.
- **Dynamic Resume Generator:** Uses `jsPDF` to generate and download a formatted resume directly from the browser—no backend required.
- **Mobile Responsive:** Hamburger menu with a sliding overlay and fully responsive grids for all screen sizes.

### 🚀 Getting Started

To get a local copy up and running on your machine, follow these simple steps.

**Prerequisites**
You just need a modern web browser. (Chrome, Firefox, Safari, Edge)

**Installation**
1. Clone the repository
   ```sh
   git clone https://github.com/deepak2020singh/portfolio.git
   ```
2. Navigate to the project folder
   ```sh
   cd portfolio
   ```
3. Open `index.html` in your browser
